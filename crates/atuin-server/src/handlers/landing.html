Atuin

Search your shell history and keep it in sync across your devices. This is a self-hosted Atuin sync server. History contents are encrypted on your devices before being synced.

1. Install the client

On Linux or macOS, install the official Atuin client:

curl --proto '=https' --tlsv1.2 -LsSf https://setup.atuin.sh \
  | sh -s -- --non-interactive

See the installation guide for Windows, package managers, and shell integration. Restart your shell after setup.

2. Configure sync

Add these top-level settings to ~/.config/atuin/config.toml. Use this server's public URL as sync_address:

{{CONFIG}}

3. Sign in and sync

atuin login
atuin sync

{{LOGIN}}

If you are already signed in to another server, run atuin logout first. Keep your Atuin encryption key and use the same key on every device.

To bring your existing shell history into Atuin, run atuin import auto, then atuin sync. Use Ctrl + R to search your history.
